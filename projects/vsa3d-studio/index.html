Engineering software / 2026

VSA3D Studio

A personal prototype for exploring how part tolerances contribute to variation in an assembly.

My role

Personal software prototype.

Tools & methods

  • Monte Carlo
  • Tolerance analysis
  • CAD geometry

The question

When parts vary within their manufacturing tolerances, which inputs drive variation in the assembled result? I wanted a small tool that made the connection between the geometry, the tolerance assumptions, and the output easier to inspect.

How the prototype works

The prototype supports plane-to-plane distance measurements, including planes on different components. Monte Carlo sampling propagates input variation through the study so that the resulting spread can be inspected alongside the underlying measurement definition.

What I’m exploring

I’m interested in making tolerance studies easier to audit. A reviewer should be able to trace a result back to the features, assumptions, and input distributions that produced it.
